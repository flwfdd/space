# 足迹页面

`/footprints` 是独立的地球页面，展示跨年合并的区域足迹，不公开位置对应的年份。页面支持拖动、缩放、区域点选、全景复位和明暗主题；年份按钮只切换记录点总数和里程，不筛选地图，不生成路线或回放。

## 数据导入

使用 Node.js 24 和项目的 pnpm 命令，从下一生足迹导出的 CSV 生成本地数据：

```sh
pnpm footprints:import /path/to/backUpData-all.csv --from-year 2023
pnpm dev
```

导入器读取 `dataTime`、`longitude`、`latitude`、`accuracy`、`distance`，以 `Asia/Shanghai` 时区计算年度汇总。空间数据在 H3 r7 网格内跨年累计采样数，在 100 条封顶后按对数转换为 8 档强度，不生成年度位置列表。无效坐标/时间会被排除；定位误差大于 1,000 米的点不绘制，未知或零精度不等于零误差。输出坐标是网格中心，保留三位小数。粒度由 `src/lib/footprints.ts` 中的 `FOOTPRINT_RESOLUTION` 统一定义。距离统计规则见下文，与地图的精度过滤分别处理。

`--from-year` 指定展示的起始年份（含），早于该年的记录在聚合前排除，并单独报告数量；不传时保留全部有效年份。上面的命令从 2023 年开始。历史补点可能带有很早的时间戳，导入器不会仅因记录少或精度为零就自动判错，也不会修改原始文件。

输出为 `public/footprints/annual.json`，格式如下：

```ts
interface FootprintData {
  version: 4;
  resolution: 7;
  points: [longitude: number, latitude: number, level: number][];
  years: {
    year: number;
    records: number;
    distanceMeters: number;
  }[];
}
```

采用普通 JSON。h3-js 和 csv-parse 仅用于本地导入，不进入浏览器。`level` 为 1–8 的整数：将 `log(1 + 采样数)` 在 1–100 条之间归一化后分档，对应全历史采样数区间 `1–2`、`3–5`、`6–9`、`10–17`、`18–31`、`32–56`、`57–99`、`100+`。这些等级描述采样强度，不是到访次数或停留时长；100 条与数万条输出完全相同。分级在导出前完成，公开位置列表不含每格精确数量、年份、逐年等级或排序名次。前端拒绝旧版格式及混入年度位置字段的数据，旧数据需重新导入。

`years` 只保留 `year`、`records`、`distanceMeters`。`records` 为该年通过地图过滤的定位采样总数，不是到访次数，也不关联具体网格；每格强度封顶不影响这一年度总数。个别年份若没有可绘制的点但存在有效里程，允许 `records` 为零并保留里程。

## 距离统计

CSV 的 `distance` 是应用导出的逐条距离字段，单位为米。本地将其与相邻定位点的球面距离比对，大多数记录吻合，说明它对应记录间的距离增量；少量记录不一致，不能将导出文件的相邻行等同于应用采样时的相邻定位回调。

当前备份按下面的规则计算后，与用户核对的应用总里程在显示的两位小数上一致：

```text
年度里程（米）= Σ distance，其中 distance 是有限数，且 0 < distance < 10,000
总里程（公里）= Σ 年度里程 / 1,000
```

这是数据比对得到的规则，[官方应用介绍](https://apps.apple.com/cn/app/id1225520399)未公开算法，不能证明应用内部只有这项过滤。备份中没有恰好 10,000 米的记录，无法区分官方边界使用 `<` 还是 `≤`；导入器明确采用 `<`。

年份和私有区域排除同时作用于点图与里程。里程在地图精度过滤之前累计，定位误差大于 1,000 米的记录仍可贡献有效距离，以保持本次核对的口径。无效、负数或超长的距离不计入里程，但不会因此删掉有效的地图点。缺少 `distance` 列会报错，避免误显示零里程。

年度距离按当前记录的 `dataTime` 归年，输出 `distanceMeters` 并保留到毫米，浏览器只做年度求和和公里格式化；切换年份同步更新距离。只输出汇总，不输出逐段距离或原始时间。无需排序、补线或从 H3 网格中心反算里程。

这项统计是记录里程，不是完整的实际出行长度。过滤超长段可能遗漏飞行或长时间停采期间的移动，也不能保证剔除所有定位漂移。

## 隐私与发布

原始 CSV/GPX、照片原件和排除规则存放在公开仓库之外。准备公开的 `public/footprints/annual.json` 与 `public/maps/countries-50m.json` 使用 Git LFS 跟踪。重新导入后先在本地检查数据，再提交更新；分析用的数据通过 `--output` 导出到仓库外。

新克隆或 CI 构建需启用 Git LFS，并在构建前执行 `git lfs pull`，确保这两个 JSON 已还原为完整文件。构建时它们会原样复制到 `dist/`，沿用站点部署流程；浏览器通过站点自身的 URL 加载，不直接请求 Git LFS 服务。

分级封顶减少精确频次与极端高频排名的泄露，跨年合并移除位置与年份的对应关系。公开网格的位置和相邻分布仍可能暴露常驻片区或学校；当前版本没有自动识别或粗化家、学校等敏感区域。需要保护具体地点时，使用下述私有排除规则，并为周边活动与连接路段留出足够范围。规则对所有年份一致生效。

如需隐藏敏感区域，在仓库外准备一个 JSON 数组，每项包含 `longitude`、`latitude`、`radiusKm`，并执行：

```sh
pnpm footprints:import /path/to/backUpData-all.csv --from-year 2023 --exclude /private/path/exclusions.json
```

导入器会保守排除与圆形区域相交的整个 H3 格子；同一格中圆外的点也被排除。原始坐标和精确时间不会输出。r7 依然能透露所在地区，聚合不等于匿名。`--output` 可指定其他本地输出路径。

## 页面实现

- `src/lib/footprints.ts`：年度汇总与跨年强度数据类型、运行时校验。
- `src/lib/footprints-map.ts`：MapLibre 地球、图层、年度统计切换和地图操作。
- `src/lib/footprints-basemap.ts`：VersaTiles 矢量细节、中文地名、按需地形与远程服务回退。
- `src/lib/globe-rotation.ts`：全景闲置时的自动旋转、交互暂停和生命周期清理。
- `src/pages/footprints.astro`、`src/styles/footprints.css`：页面和响应式布局。
- `scripts/import-footprints.ts`：本地 CSV 加工。

数据一次加载。空间数据在本地跨年合并、分级并按网格编号排序，浏览器只创建一份不含年份的 GeoJSON 点源。年份按钮只更新汇总数字，不修改图层、点集、相机或选中的位置。大量点使用单个原生 circle 图层，点大小只由等级和缩放决定，不创建逐点 DOM，也不叠加模糊辉光。弹窗只显示足迹强度，不显示精确记录数；概览显示所选年份或全部年份的距离与记录点总数，年份条高度按年度距离计算。区域显示的是粗化后的覆盖位置。

点半径按等级线性递增，远景和中景压低最大点径，放大后逐渐拉开档位差异，减少密集区域重叠；在缩放 0、4、6、8、9 级时，半径分别为 0.35–0.65、0.7–1.35、1–2.2、1.6–4.2、2.2–6.6 像素，缩放期间平滑插值。强度档位在本地导入时已按对数划分，渲染时直接映射到点径。

MapLibre 的模块 Worker 通过 Vite `?worker&url` 显式打包，避免在开发或生产环境中按错误相对路径加载。设备像素比最高为 2，地图只在页面激活后初始化。导航禁用该路由的悬停预渲染。页面离开时释放地图及监听器，浏览器往返缓存保留状态。

默认全景从北回归线附近观察，纬度中心为北纬 23.44°，bearing、pitch 与 roll 均为 0°，不额外添加地轴侧倾。关闭带有方向光源的大气散射，避免球体边缘出现局部亮斑。全景加载后等待 1.5 秒开始自转，速度逐渐增加至每秒 3 度，稳定后约两分钟一圈。按真实帧间隔推进，跨越经度边界时归一化；卡顿后限制单帧位移，避免跳转。

拖动、触摸、滚轮、键盘和按钮操作立即暂停。交互及相机动画结束后闲置 8 秒，清除区域选择，用 6 秒五次 S 曲线（smootherstep）恢复默认大小、纬度与正向视角；曲线两端速度与加速度均为零，起步和收尾柔和，中段逐渐加速再减速。旋转速度也随同一曲线恢复。保留当前经度；手动点击全景按钮则回到初始经度。退出细节视图时按缩放降低旋转速度，避免近景快速横移。页面隐藏、WebGL 上下文丢失或启用“减少动态效果”时停止。暂停时取消动画帧，页面离开时同时清理计时器与监听器；浏览器往返缓存恢复后重新等待。

页面使用 `Layout.astro` 的 `immersive` 选项，提供全宽主区域并省略波浪页脚，导航、字体与主题仍与全站一致。`footprints.css` 仅负责地球页面的布局，不覆盖全站导航或维护另一套明暗配色。正文与标题使用 `--font-serif`，辅助信息使用 `--font-sans`，数据标签使用 `--font-mono`；地图操作、年份和重试按钮复用 `.btn` / `.btn-ghost`。

页面颜色来自 `design.css` 的 `--color-surface`、`--color-surface-raised`、`--color-text`、`--color-text-muted`、`--color-border`、`--color-primary` 与 `--color-accent`。地球海洋、边界由这些 token 混色，足迹点使用全站橙色；WebGL 颜色在初始化及切换主题时通过 1 像素 Canvas 将 OKLCH / color-mix 转成 sRGB，避免另存固定色值或让地图解析不支持的 CSS 语法。

地图代码、Worker、足迹及备用轮廓同源加载。详细底图和高程统一直连 `tiles.versatiles.org`，使用 `osm-vector` 与 `elevation-raster`，不增加瓦片代理或存储。地图西文字形使用该服务的 `noto_sans_regular`；中文优先在本地用全站 Noto Sans SC / 系统回退字体生成。页面字体继续沿用全站样式。

首屏先显示本地轮廓和足迹，再在同一个画布中加载详细底图。底图首次就绪后淡入；12 秒仍未就绪时保持原有地球。服务已就绪后，零星瓦片失败保留其他已加载内容；连续至少三次失败且随后 8 秒没有成功加载的底图瓦片时，隐藏远程图层并回到本地轮廓。回退在本次页面停留期间保持，刷新可重新尝试。切换年份与主题不重建地图。

`/footprints?basemap=local` 可单独预览备用轮廓，跳过在线底图与山体加载，用于检查轮廓简化效果；无参数时使用正常的自动增强流程。

缩放上限为 9，保留城市及周边区域尺度，进入细节视图后淡出大标题与概览统计，为地图腾出空间。国名从 2.5 级出现，省名从 4.5 级、主要城市和城镇从 5 级出现，省界按源数据从 7 级显示，细水系从 9 级显示。地名优先简体中文，其次中文、原名和英文；标签参与碰撞避让。默认地球视角不显示山体，首次放大到 2.75 级才加载高程，并从国家到省级尺度逐渐显现；standard 算法将渐显区间延伸到 6.25 级，近景略微减弱以免细碎纹理过重。保留完整山体细节，以低不透明度控制明暗强度。浅色主题关闭高光，深色主题从全站主色生成 3% 不透明度的坡面亮部，随主题同步更新；平地不受光照影响。海洋与湖泊覆盖在阴影之上，地形瓦片局部失败不阻止其他图层使用。足迹继续采用 r7 聚合精度。

本地足迹或轮廓加载失败、WebGL 不可用时显示重试入口；远程底图、字体和地形错误不显示整图错误遮罩。年度统计在地图不可用时仍可切换。尊重减少动态效果设置，地图控件和年份按钮支持键盘操作。

## 地理资源

`public/maps/countries-50m.json` 来自 Natural Earth v5.1.2 的 1:50,000,000 国家轮廓，仅保留中文名称、几何信息和数字 ID，坐标取三位小数。这里的“50m”是制图比例尺名称，不是 50 米定位精度。轮廓经 Mapshaper 的默认 weighted Visvalingam 算法简化，参数为 `-simplify 15% keep-shapes`，输出使用 `format=geojson precision=0.001` 并移除多余空白；共享边界统一处理，保留 242 个国家和地区及其名称、ID，部分微小岛屿被省略。当前文件约 304 KB，gzip 约 109 KB，仅用于首屏和故障兜底，不降低在线底图与山体精度。简化离线完成，不引入运行时依赖。

- [原始 GeoJSON](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_50m_admin_0_countries.geojson)
- [Natural Earth 公有领域声明](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/LICENSE.md)
- MapLibre GL JS：BSD-3-Clause；h3-js：Apache-2.0；csv-parse：MIT。

本地轮廓用于首屏与服务故障时的概览。在线底图采用 VersaTiles 的 Shortbread 矢量数据，展示国界、省级边界、地名和水系；不承诺完整市县边界。高程为 VersaTiles 分发的 Mapterhorn 数据，以 Terrarium 编码的 512 像素 WebP 瓦片提供，最高原生缩放 12。页面按原生瓦片尺寸与缩放范围加载，保留放大后的山体细节。来源署名按实际显示的图层出现在页面底部。

- [Shortbread 图层定义](https://shortbread-tiles.org/schema/1.0/)

## 检查

运行 `pnpm astro check && pnpm build`。交互检查桌面和手机、快速年份切换、点选、缩放与复位、主题同步；年度距离与记录点总数随年份更新，地图点集保持不变，切回全部时恢复累计统计。底图检查中文地名、按需地形、服务不可用时回到本地轮廓且统计与操作正常。自动旋转检查初始缓入、交互暂停与闲置恢复、细节视图缓入缓出地退回正向全景、减少动态效果和页面生命周期。数据检查跨年时区、起始年份过滤、无效记录、区域排除、距离阈值与地图精度过滤的独立性、跨年合并后的强度分档与高频封顶，以及公开产物不包含年度位置列表、位置年份、原始定位字段或每格精确计数。
